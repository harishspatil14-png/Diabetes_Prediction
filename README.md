# 🩺 Diabetes Prediction System

## 📌 Project Overview
The **Diabetes Prediction System** is a Machine Learning project that predicts the likelihood of diabetes based on user-provided health information. It uses a trained machine learning model to analyze input features and display a prediction through a user-friendly web interface.

## 🎯 Objectives
- Predict the likelihood of diabetes using Machine Learning.
- Provide a simple and user-friendly interface.
- Connect a React frontend with a Python Flask backend.
- Display prediction results in an easy-to-understand format.

## 🛠️ Technologies Used
- **Frontend:** React.js, CSS
- **Backend:** Python, Flask
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Dataset:** `diabetes.csv`

## ✨ Features
- User-friendly web interface.
- Health-related input fields for prediction.
- Machine Learning-based prediction.
- Displays the prediction result and likelihood percentage.
- Backend integration using Flask API.

## ⚙️ How It Works
1. The user enters the required health information.
2. The frontend sends the input data to the Flask backend.
3. The trained Machine Learning model processes the input.
4. The system displays the prediction result on the webpage.

## 🚀 Installation and Setup

### 1. Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

### 2. Install Backend Dependencies
```bash
pip install flask flask-cors pandas numpy scikit-learn
```

### 3. Run the Flask Backend
Run your Flask application using the appropriate Python file. For example:

```bash
python app.py
```

### 4. Run the React Frontend
Open another terminal and navigate to the frontend folder.

```bash
npm install
npm start
```

*Note: Use the commands and filenames that match your actual project structure.*

## 📊 Dataset
The project uses a diabetes dataset stored in `diabetes.csv` to train and evaluate the Machine Learning model.
